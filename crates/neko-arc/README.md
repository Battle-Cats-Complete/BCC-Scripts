## Neko-Arc

**COMMAND:** `neko-arc`

Handles "The Battle Cats Unite" Nintendo Switch version. Unpacks `FCRA` (`.arc`) archives, resolves the hashed file names inside them back to their original mobile names, and converts the Nintendo containers to standard file formats.
